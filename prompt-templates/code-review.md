---
name: code-review
category: review
description: 对指定文件或目录进行多维度代码审查
params:
  - name: target
    description: 要审查的文件路径或目录
    example: src/auth/login.ts
  - name: focus
    description: 审查重点关注的方面
    example: 安全性、性能、错误处理
---

对 {{target}} 进行代码审查，重点关注 {{focus}}。

请按以下维度逐一检查并给出结论：

1. **正确性** — 逻辑是否有 bug，边界条件是否处理
2. **安全性** — 是否存在注入、越权、信息泄露等风险
3. **性能** — 是否有不必要的重复计算、内存泄漏、阻塞操作
4. **可读性** — 命名是否清晰，结构是否合理，注释是否充分
5. **健壮性** — 错误处理是否完善，异常路径是否覆盖

输出格式：
- 每个维度给出 ✅（通过）或 ⚠️（建议改进）或 ❌（需要修复）
- 对于非 ✅ 的项，给出具体位置、问题描述和修复建议
- 最后给出总体评价和优先修复建议
